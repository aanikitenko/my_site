Git: система контроля версий

Git — это распределённая система контроля версий, которая позволяет отслеживать изменения в файлах и работать над проектом в команде.

Основные команды

  • git init — создать новый репозиторий
  • git add — добавить файлы в отслеживание
  • git commit -m "message" — сохранить изменения
  • git push — отправить изменения на удалённый репозиторий
  • git pull — скачать изменения с удалённого репозитория
  • git clone — скопировать удалённый репозиторий
  • git branch — посмотреть список веток
  • git merge — слить ветки

Ветки

Ветки позволяют работать над разными версиями проекта параллельно. Основная ветка обычно называется main или master.

GitHub

GitHub — это платформа для хостинга Git-репозиториев. С его помощью можно делиться кодом, работать в команде и публиковать сайты через GitHub Pages.

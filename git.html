Git: система контроля версий

Git — это распределённая система контроля версий, которая позволяет отслеживать изменения в файлах и работать над проектом в команде.

Основные команды:

  • git init — создаёт новый репозиторий
  • git add — добавляет файлы в отслеживание
  • git commit -m "message" — сохраняет изменения
  • git push — отправляет изменения на удалённый репозиторий
  • git pull — загружает изменения с удалённого репозитория
  • git clone — копирует удалённый репозиторий

Git позволяет работать с ветками (git branch, git merge), что даёт возможность разрабатывать новые функции параллельно. GitHub — самая популярная платформа для хостинга Git-репозиториев, которая также предоставляет бесплатный хостинг для статических сайтов через GitHub Pages.

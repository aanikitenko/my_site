## Что такое Git?

Git — это система контроля версий, которая позволяет отслеживать изменения в файлах.

## Основные команды

- `git init` — создать репозиторий
- `git add .` — добавить файлы
- `git commit -m "message"` — сохранить изменения
- `git push` — отправить на GitHub
- `git pull` — скачать изменения

Markdown — лёгкий язык разметки

Markdown — это простой язык разметки, который позволяет форматировать текст без использования мышки.

Основной синтаксис:

  • # Заголовок 1
  • ## Заголовок 2
  • **жирный текст**
  • *курсив*
  • - пункт списка
  • [ссылка](url)

Markdown используется везде: в GitHub (README, issues, comments), в Hugo (написание постов), в Telegram, в Jupyter Notebooks и многих других местах. Его главное преимущество — простота и читаемость даже в исходном виде.

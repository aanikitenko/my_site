Markdown — лёгкий язык разметки

Markdown — это простой язык разметки, который позволяет форматировать текст без использования мышки.

Основной синтаксис

  • # Заголовок 1
  • ## Заголовок 2
  • ### Заголовок 3
  • **жирный текст**
  • *курсив*
  • - пункт списка
  • 1. нумерованный список
  • [ссылка](url)
  • `код в строке`

Где используется

  • GitHub (README, issues, comments)
  • Hugo (написание постов)
  • Telegram (форматирование сообщений)
  • Jupyter Notebooks
  • Документация проектов

Преимущества

  • Простота — не нужно отвлекаться на форматирование
  • Читаемость — текст понятен даже в исходном виде
  • Переносимость — работает везде
